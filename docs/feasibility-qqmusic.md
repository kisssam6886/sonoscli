# QQ 音乐可行性验证（草案）

## 目标
验证 QQ 音乐是否适合作为 `sonoscli-plus` 下一批 Service Adapter。

## 验证维度
1. 搜索能力：歌手 / 歌曲 / 榜单
2. 可播性与稳定性：队列、metadata、起播成功率
3. 授权与维护成本：token 生命周期、风控、维护工作量
4. 合规风险：接口稳定性、服务条款风险

## 验收标准（建议）
- 基础搜索成功率 >= 95%
- 连续 30 次起播成功率 >= 95%
- metadata 完整（title/artist/album）>= 95%
- 授权流程可自动化或半自动化
